## 💡 Example Usage

```python
from quantum_forge_v2 import QuantumForge
from vector_gen_v2 import SymbolicVectorGenerator, VectorChainBuilder

# Create agent
forge = QuantumForge()
agent = forge.generate_agent(
    agent_type="ResearchAgent",
    intent_description="Quantum-symbolic research",
    capabilities=["literature_review", "synthesis"]
)

# Build vector chain
generator = SymbolicVectorGenerator()
builder = VectorChainBuilder(generator)
chain = builder.create_chain(
    chain_type=VectorChainType.SEQUENTIAL,
    constellation_target=ConstellationTarget.ZIPWIZ
)
```
