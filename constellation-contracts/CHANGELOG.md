# Changelog

All notable changes to the Aurora Constellation Contracts will be documented in this file.

## [1.0.0-alpha] - 2026-03-13

### Added
- Initial contract registry for the Aurora Constellation (Architecture Proposal v1.0.0)
- JSON Schemas: forecast-request, forecast-result, constellation-event, knowledge-index, constellation-health, manifest
- OpenAPI 3.0 specification for the constellation gateway API
- Python dataclass type definitions with jsonschema validation
- TypeScript interface and Zod schema type definitions
- Template manifests for all 5 spoke repos
- Constellation hub manifest (.aurora/constellation.json)
- GitHub Actions workflows: event router, event publisher, integration CI, health audit
- QGIA knowledge indexer and knowledge bridge modules
