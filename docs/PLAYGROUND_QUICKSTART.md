# Try it in the Playground

Anchor: T1-PLAYGROUND-STARTER
Ethics: Picard_Delta_3

## Steps

1. Install deps and start the frontend:
   ```bash
   npm install
   npm run dev -- --host --port 5173
   ```
2. Open [http://localhost:5173/playground](http://localhost:5173/playground).
3. Pick a starter scenario (quantum, memory, thread bridge, decision) and copy the **metadata anchors** shown at the top of each card.
4. Keep the default PII redaction payload (`strategy: mask`, fields: `full_name`, `email`, `phone`) when you share/fork sessions.
5. Use the Python + JS snippets side-by-side to validate continuity before promoting a session to collaborators.
