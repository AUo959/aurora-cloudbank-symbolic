# Operational Documentation

This directory contains operational documentation, status reports, and historical records that were previously scattered in the root directory.

## Directory Structure

- `status/` - Current status reports and health checks
- `completed/` - Historical completion reports and phase documentation
- `guides/` - Operational guides and procedures
- `reports/` - Analysis reports and diagnostics
- `archived/` - Archived documentation no longer actively maintained

## Quick Reference

For current project status, see [`status/current-status.md`](status/current-status.md).
For deployment information, see [`guides/deployment-guide.md`](guides/deployment-guide.md).
For security reports, see [`reports/security-summary.md`](reports/security-summary.md).
