## 🛠️ Usage Examples

### Creating an Agent

```python
from quantum_forge_v2 import QuantumForge, EthicsLevel, FlowstateMode

# Initialize
forge = QuantumForge(
    ethics_level=EthicsLevel.BALANCED,
    flowstate_mode=FlowstateMode.GENERATIVE
)

# Generate agent
agent = forge.generate_agent(
    agent_type="ResearchAgent",
    intent_description="Conduct quantum-symbolic research",
    capabilities=[
        "literature_review",
        "pattern_synthesis",
        "hypothesis_generation"
    ],
    joy_weight=0.8
)

print(f"Agent ID: {agent.agent_id}")
print(f"Alignment: {agent.intent_alignment_score:.3f}")
```

### Creating a Vector Chain

```python
from vector_gen_v2 import (
    SymbolicVectorGenerator,
    VectorChainBuilder,
    VectorChainType,
    ConstellationTarget
)

# Initialize
generator = SymbolicVectorGenerator(default_dimension=512)
builder = VectorChainBuilder(generator)

# Create chain
chain = builder.create_chain(
    chain_type=VectorChainType.SEQUENTIAL,
    constellation_target=ConstellationTarget.ZIPWIZ,
    chain_name="My_Custom_Chain"
)

# Generate vectors
operations = [
    {"tag": "🧭", "id": "vec1", "text": "First operation"},
    {"tag": "🔑", "id": "vec2", "text": "Second operation"}
]

vectors = generator.generate_operational_vectors(operations)

# Inject into chain
for vector in vectors:
    builder.inject_vector(chain.chain_id, vector)

# Auto-link
builder.auto_link_sequential(chain.chain_id)
```
